# Мастерская литья — серебро и олово

Личный интерактивный гайд для домашней мастерской: пошаговые мастера с анимированными SVG-схемами, термометр металлов, покупки, калькулятор металла, таймеры, дефекты и журнал отливок. Один статический сайт, без сервера и без сборки, работает офлайн (PWA).

## Запуск на компьютере

Нужен Node.js (любой современный).

```
node serve.mjs
```

или двойной клик по `start.cmd`. Откроется на http://localhost:8080.

**С iPhone:** телефон в той же Wi-Fi сети → адрес вида `http://192.168.x.x:8080` (сервер печатает его при старте). Если не открывается — разреши Node.js в брандмауэре Windows для частной сети.

> По http с телефона офлайн-режим и уведомления не включаются — браузер разрешает их только по https. Для этого — GitHub Pages ниже.

## Публикация на GitHub Pages

1. Создай репозиторий, загрузи в него содержимое этой папки (папку `tools/` можно не загружать).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`.
4. На iPhone: открой в Safari → «Поделиться» → **«На экран Домой»**. Дальше работает без интернета.

После изменения файлов подними `VERSION` в `sw.js` — иначе телефон может показывать старую версию из кэша (обновится со второго открытия).

## Данные

- Отметки, цены, прогресс, заметки, таймеры, журнал — `localStorage` (ключи `mc.*`).
- Фото журнала — IndexedDB (`mc-photos`), сжатые до 1280 px: в localStorage влезло бы ≈30 фото.
- Раздел «Данные» (внизу главной): резервная копия в `.json`, восстановление, сброс.
- Safari стирает данные сайтов, которые не открывали ≈7 дней. Установка на экран «Домой» и резервная копия защищают журнал.

## Структура

```
index.html            оболочка + общие SVG-градиенты
css/app.css           тема «кузница», токены олово/серебро
js/app.js             роутер (#/…), верхняя панель, нижняя навигация
js/core.js            режим, прогресс мастеров, чек-лист безопасности
js/timers-core.js     таймеры (по часам), звук, уведомления, «не гасить экран»
js/store.js, ui.js    хранилище, фото, тосты, диалоги
js/svg/scenes.js      все иллюстрации мастеров (SMIL-анимации)
js/data/*.js          тексты: мастера, покупки, правила моделирования, дефекты
js/views/*.js         экраны разделов
tools/make-icons.mjs  генератор PNG-иконок (node tools/make-icons.mjs)
serve.mjs             локальный сервер без зависимостей
```

Тексты шагов правятся в `js/data/wizards.js`: `text` — абзацы, `notes` — плашки `danger` ⚠️ / `warn` 🟡 / `tip` 🟢.
